# OWL GRIDBREAKERS v1.3.0 — Save compatibility

## Antes de atualizar
1. Abra a versão atual do jogo usando a mesma URL/porta de sempre.
2. Clique no botão 💾 e escolha **Export save (.json)**.
3. Guarde o arquivo JSON em uma pasta segura.

## Atualização
1. Extraia `OWL_GRIDBREAKERS_v1.3.0.zip` em uma pasta nova.
2. Inicie o jogo normalmente (`Iniciar-Jogo.bat` ou `Iniciar-Jogo.ps1`).
3. Use o mesmo navegador e a mesma origem (host + porta) usados pela v1.2.
4. O jogo mantém a chave `awo_save_v1` e acrescenta apenas `campaignV13`; não apaga heróis, níveis, XP, equipamentos, moedas, invocações ou progresso.

## Rollback
Se precisar voltar à v1.2, feche o jogo e restaure a cópia JSON pelo botão 💾 ou mantenha a pasta v1.2 intacta. Não limpe os dados do navegador.

## Nova campanha
Cada estágio possui 33 encontros: ondas 1–31 normais, onda 32 mini-chefe e onda 33 chefe final. A progressão de estágios continua limitada aos 100 estágios existentes.
